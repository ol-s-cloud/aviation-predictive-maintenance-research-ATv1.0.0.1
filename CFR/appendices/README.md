## How to Use

1. **Reference from main sections:** When you have detailed data that would interrupt the flow of the main report, place it here and reference it.

2. **Linking format:**
   ```markdown
   For detailed survey results, see [Appendix A: Survey Data](../appendices/survey-data.md).
   ```

3. **Naming convention:** Use clear, descriptive names for any additional appendices you create.

---

## Guidelines

- Keep appendices well-organized and clearly labeled
- Each appendix should have a clear title and description
- Include references back to the main section that uses this data
- Use tables, charts, and visualizations where appropriate
- Maintain consistent formatting with the rest of the report
